### "Describe a time you owned a feature end-to-end"

> At TiMoto AI, I built the entire ML serving layer from scratch. The requirement was: serve concurrent LLM inference requests without OOM errors and at sub-50ms p99.
>
> I evaluated three approaches. Naive batching would exhaust KV cache under concurrent load. A managed API would limit our ability to tune latency and cost. vLLM with PagedAttention was the right choice -- it eliminates KV cache fragmentation by treating memory like virtual pages.
>
> I designed the gRPC front-end, selected vLLM, wrote the deployment manifests, and set up CloudWatch + Prometheus observability. Then we hit a deadlock: concurrent gRPC calls were acquiring shared resources in inconsistent order. I traced the conflict, redesigned the call sequencing, and eliminated it.
>
> Result: zero OOM failures, sub-50ms p99, 100% evaluation success rate. I owned every layer -- model selection, serving, IPC, ops.
